About jdgrid

jdgrid is the personal hub of a Korea-based solo developer. Focused on shipping small, focused tools that do one thing well and run entirely in the browser.

What you'll find here

  • Free dev utilities — see the Projects section
  • Long-form technical writing tied to the tools (on yutils)
  • Open-source friendly, privacy-first defaults

Operating principles

  • Client-side first — user data stays in the browser whenever possible
  • No login walls — tools work immediately without an account
  • Honest performance — small bundles, no dark patterns
  • Documentation alongside code — every tool has a guide

Stack

Next.js, TypeScript, Tailwind, Cloudflare Workers. Built and maintained by one person.

Email support@jdgrid.com for questions, bug reports, or partnership inquiries.
